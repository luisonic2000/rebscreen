# Libre Hardware Monitor — componente opcional

Esta cópia portátil é fornecida somente para habilitar telemetria local de temperatura e SMART. Abra `LibreHardwareMonitor.exe`, depois use `Options > Web Server > Run web server`; o Rebscreen lê apenas `http://127.0.0.1:8085/data.json`.

Origem: Libre Hardware Monitor oficial. Consulte o projeto oficial para licença e atualizações. Não é necessário para abrir o Rebscreen.
